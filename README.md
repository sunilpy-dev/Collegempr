# 🔐 Login & Signup Page

A clean and responsive **Login and Sign-Up interface** built using **HTML and CSS** for a college project.  
This project focuses on **UI layout, form design, and responsive styling**, following modern authentication page design patterns.

## Project overview
This project was created as part of a **college assignment** to understand how **authentication interfaces** are designed and styled using only **HTML and CSS**.

It demonstrates:
- Form layout and alignment
- Clean UI spacing and typography
- Input styling and focus states
- Responsive layout for different screen sizes

---

## Key features
- Separate **Login** and **Sign-Up** pages  
- Well-styled input fields and buttons  
- Clean and modern UI layout  
- Fully responsive design  
- User-friendly form structure  

---

## Technologies used
- **HTML5**
- **CSS3**
- No JavaScript (UI-only frontend prototype)

---

## How to run locally
1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` (or `login.html`) in any web browser  

The login and signup pages will load instantly.
